# Project Initialization

Use this skill only as a Codex entry point to the canonical product workflow. Load and
follow `AGENTS.md`, `agent-system/README.md`,
`agent-system/roles/product.md`, `agent-system/workflows/lifecycle.yaml`, the shared
policies, `agent-system/contracts/handoff.md`, `docs/PRD.md`, and
`features/INDEX.md`.

Do not add product or lifecycle rules here. Produce the artifacts required by the
product role, preserve approval boundaries, and finish with the shared handoff.
