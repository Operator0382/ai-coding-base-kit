# Feature Index

> Canonical lifecycle status for all features. Status changes follow the approval and
> ownership rules in `agent-system/workflows/lifecycle.yaml`.

## Status Legend
- **Roadmap** - `/init` done, feature identified in feature map, no spec file yet
- **Planned** - `/write-spec` done, full spec written, architecture not yet designed
- **Architected** - `/architecture` done, tech design approved, ready to build
- **In Progress** - `/frontend` or `/backend` active or completed, not yet in QA
- **In Review** - `/qa` active, testing in progress
- **Approved** - `/qa` passed, no critical/high bugs, ready to deploy
- **Deployed** - `/deploy` done, live in production

## Status Update Rule

After a lifecycle transition is complete and the user has approved it, the role that
completed the transition may update only the status cell in that feature's row and
must re-read the row. Product owns every other change to this file.
