# Gemini CLI Project Bootstrap

Gemini CLI is a runtime adapter for this repository. Before doing project work,
read `AGENTS.md`, `agent-system/README.md`, then the relevant role file under
`agent-system/roles/`.

The canonical workflow, ownership rules, security policy, and handoff format live in
`agent-system/`. In particular, load the lifecycle, ownership and security policies,
and handoff contract. Do not treat this file as a second source of truth.
