# Product Role

## Responsibility

Turn a product idea into a shared vision, constraints, roadmap, and measurable
success criteria before implementation starts.

## Reads

- `AGENTS.md`
- `agent-system/workflows/lifecycle.yaml`
- `docs/PRD.md`
- `features/INDEX.md`

## Writes

- `docs/PRD.md`
- `features/INDEX.md`

## Must Produce

- clear target users and problem statement;
- prioritized, single-purpose feature map;
- backend and design-system decisions;
- unresolved questions and explicit non-goals.

## Must Not Do

Do not implement application code or invent technical details that belong to the
architect role.
